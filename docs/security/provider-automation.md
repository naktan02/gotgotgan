# Provider automation

This personal prototype accepts provider suspension, parser churn, and limited-distribution product
risk without a broad legal-review gate. It still does not bypass MFA, CAPTCHA, access controls, or a
method known to be prohibited. Those states pause for user action or switch to export, official API,
manual capture, or a separately reviewed connector.

Live-provider checks are opt-in. Deterministic sanitized fixtures block merges and releases.
