곳곳간 · 가져오기 연결 확인

연결된 서비스의 내 즐겨찾기 목록과 기본 장소 정보를 읽습니다. 로그인이 필요할 때만 해당 서비스 창을 엽니다.

로그인 창에서 직접 인증하면 상태를 확인한 뒤 창을 자동으로 닫고 수집을 계속합니다. 확인 전에 창을 닫으면 작업이 중단됩니다.

기본 정보 수집을 누르면 로그인 상태부터 확인합니다.

현재 연결 확인 단계입니다.

수집한 정보는 서버나 파일에 저장하지 않습니다. 메뉴 등 상세정보는 수집하지 않습니다. 앱을 종료하면 로그인 세션과 수집 데이터는 사라지므로 다음 실행 때 다시 로그인해야 합니다.

로그인·2차 인증·보안 확인은 해당 서비스 화면에서 직접 진행합니다. 인증 확인은 최대 5분 동안만 진행합니다.
