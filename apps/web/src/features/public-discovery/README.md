# 공개 목록 둘러보기

이 feature는 공개 Collection 검색·선택·일부/전체 복사·공유 링크·작성자 신고를 소유한다.
`public.ts`만 app 조립 계층에 공개하며, Provider 계정이나 개인 기록을 조회하지 않는다.

화면은 380px 작업 패널 하나와 독립 지도로 구성한다. 목록을 선택하면 같은 패널이 목록 상세로
바뀌고, 돌아오면 검색 조건·목록 스크롤·선택 버튼의 초점을 복원한다. 패널을 접어도 선택과 지도
viewport를 보존한다. 모바일은 위 지도 38%와 아래 패널 62%를 분할해 marker를 가리지 않으며,
접으면 지도가 100%를 사용한다. 데스크톱 열을 압축하지 않는다.

필터는 기본적으로 접혀 있고 큰 후보 집합은 이름 검색 뒤 최대 40개씩 표시한다. 서버가 전달한
공개 directory facet만 소비하며 loaded Collection 행에서 전체 분류나 건수를 추정하지 않는다.
추천·좋아요·인기 집계는 추가하지 않는다.

이 화면의 지도는 선택 목록의 **불러온 장소 미리보기**다. 전체 지도라고 표시하지 않으며,
독립 viewport-complete projection이 있는 기존 공유 목록 화면으로 연결한다. 공유 및 복사는
기존 version-bound 계약·동일 command 재시도를 보존하고 개인 메모·방문·사진·평점을 포함하지 않는다.
