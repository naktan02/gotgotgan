# Catalog Home

The Home feature searches only the provider-neutral Canonical Place catalog through
`/api/search/catalog`. It does not expose live NAVER, Google, or Kakao search results.

User favorites are represented by member-owned Collections. A search result is filed by choosing a
Collection; successful actions in the current browser session provide the only recent-activity
items shown by Home. The list and Collection chooser remain usable when a result has no map
coordinates or the injected map renderer fails.
