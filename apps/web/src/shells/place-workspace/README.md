# 회원 workspace shell

Finance 사용자 Web의 상단은 승인된 시각 기준이며 소스·실행 의존성이 아니다. 이 shell은 고정된
제목/인사 영역, 오른쪽 작업/테마/계정 영역, 아이콘 아래 작은 이름을 둔 76px 메뉴와 manifest 기반
패밀리 버튼을 소유한다. 모바일은 64px 상단과 56px 하단 메뉴를 사용하고 나머지 공간의 스크롤은
각 feature가 소유한다.

`PlaceWorkspaceShell`의 입력은 현재 화면, 주입한 패밀리 manifest, 안전한 계정 표시 정보와 본문이다.
검색은 해당 feature 패널에 둔다. `WorkspaceHeader`는 내부 표현 모듈이다. 프로필 응답을 엄격히
검증한 뒤 이름을 표시하며 회원 등급, 세션 보안 정보, 미지원 동작을 꾸미지 않는다. 상태 조회 실패를
알림 0개 또는 서비스 연결 성공으로 해석하지 않는다. 로그아웃은 기존 POST 경계를 유지한다.
테마 저장은 선택 사항이며 localStorage 거부가 화면 사용을 막지 않는다.

다른 프로젝트와 실제 코드를 공유하려면 별도 검토한 released package를 사용해야 한다. 형제 저장소
소스 복사·직접 import를 하지 않는다. 프로젝트별로 상단 구조를 변형하는 것은 승인된 기준이 아니며,
공통 package의 추출·배포는 이번 변경 범위가 아니다.
