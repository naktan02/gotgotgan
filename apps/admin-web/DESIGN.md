# 곳곳간 Admin 디자인 기준

## 성격

곳곳간 Admin은 검수와 운영을 위한 고밀도 작업 도구다. 사용자 앱의 밝고 탐색적인 지도 경험과
분리해 짙은 남색 sidebar, 흰색 상태 bar, 중립 배경의 workspace를 사용한다. 단, 정보 밀도는 실제
운영 Interface가 생긴 만큼만 높인다. 존재하지 않는 장소·통계·작업·정상 상태를 데모 값으로 채우지
않는다.

## 첫 화면

첫 화면의 책임은 두 가지뿐이다.

1. OIDC server session과 Backend `/v1/me`를 통해 현재 운영자의 Authority Role을 확인한다.
2. 지금 사용할 수 있는 Capability와 아직 Backend Interface가 없는 영역을 구분한다.

권한 확인 전에는 `확인 중`, 세션이 없으면 `로그인 필요`, 일반 회원이면 `접근 권한 없음`, 의존성이
응답하지 않으면 `서비스 준비 필요`를 보여준다. 검증된 운영자에게만 workspace가 준비됐다고 표시한다.

## 정보구조

- 운영 대시보드
- 장소 관리: 장소 데이터, 중복·병합/분리, 분류, 휴·폐업
- 데이터 수집: 작업, 소스, 스케줄, 로그
- 사용자 관리: 계정, 권한, 신고·이의
- 시스템: 작업, 실패, 감사, 설정

운영 대시보드와 읽기 전용 장소 데이터(`/catalog`)만 route를 가진다. 장소 화면은 공개 투영된 내부
카탈로그 검색·결과 목록·선택 상세의 두 pane이며 좁은 화면에서는 세로로 배치한다. 페이지의 표시
개수는 현재 읽은 행 수이며 전체 DB 개수로 표현하지 않는다. 나머지 항목은 `Backend Interface 미구현` 설명과
함께 disabled다. 관리자 sidebar에는 패밀리 서비스를 두지 않는다.

## 보안 표현

- 상단 역할과 접근 상태는 `/api/admin/session`의 현재 응답만 표시한다.
- 사용자 이름, 사진, 알림 개수, 수집 시각, 성공률을 추정하거나 고정 값으로 만들지 않는다.
- 브라우저는 opaque cookie만 사용하며 token이나 Backend 주소를 알지 못한다.
- `member` 역할은 화면을 숨기는 수준이 아니라 BFF에서 `403`으로 차단한다.
